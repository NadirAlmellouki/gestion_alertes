## 2. ENREGISTREMENT MANUEL : FAUCUN ENREGISTREMENT

Le problème précédent concernant l'absence de fichier encore n'est pas corrigé :

Il faut donc vérifier toute la chaîne audio.

Analyse :

Asterisk
→ channels
→ bridge
→ flux RTP/audio
→ MixMonitor / Record
→ fichier WAV
→ volume Docker
→ dossier recording du backend.
etc..

Vérifie particulièrement :

- à quel moment l'enregistrement est démarré ;
- si l'enregistrement est attaché au bon channel ou au bridge ;
- si le bridge contient réellement les deux channels ;
- si le média audio circule réellement entre les deux participants ;
- si MixMonitor reçoit effectivement de l'audio ;
- si l'enregistrement est arrêté correctement après le hangup ;
- si le fichier est fermé/finalisé correctement ;
- les permissions du répertoire ;
- le montage du volume Docker ;
- le format WAV utilisé ;
- la configuration RTP/codec ;
- les logs Asterisk pendant l'appel.

IMPORTANT :
Ne considère PAS qu'un fichier créé signifie que l'enregistrement fonctionne.

Je veux un test réel où :
- le superviseur parle ;
- l'OPS répond ;
- les deux parlent réellement pendant plusieurs secondes ;
- le superviseur raccroche ;
- le fichier final est généré ;
- sa taille est supérieure à 50 octets ;
- le fichier contient réellement la conversation audio.

Vérifie également que l'enregistrement contient bien les deux directions audio (superviseur → OPS et OPS → superviseur), et pas seulement une direction.
