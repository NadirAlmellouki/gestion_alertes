# gestion_alertes
gestion des alertes pour une banque, intégrant un modèle de langage (LLM) pour la classification automatique des alertes, un moteur de règles métier pour l'application de la logique métier, ainsi qu'un mécanisme de routage intelligent permettant de notifier et de renotifier automatiquement les destinataires concernés selon des règles prédéfinies.
